Outproof Privacy Policy

Publisher: LeonS, India
Contact: atulhritik@hotmail.com
Effective date: 31 October 2026

1. What Outproof is
Outproof is a plug-in for Autodesk Revit that checks a model before an IFC export (pre-flight report), reads an IFC file after the export and reconciles it with the model (verification), and manages a library of export setups. Optional add-on features compare two IFC files, save reports as CSV or Excel files, and keep a verification history.

2. Information we collect
We do not collect, receive or store any of your project data, model content, drawings, IFC files, setups or personal information on our servers. Outproof has no account system and no analytics.

3. Information stored on your computer and in your model
- The only data Outproof stores in a Revit model is a short note of which export setup the model uses (setup name, version number, date and file name of the last verified export). It sits on the Project Information element, so it travels with the file, and it can be removed with the "Remove all Outproof data" button in the ? guide.
- Your export setups are stored in %AppData%\LeonS\Outproof\library.json. Setups hold export options and file paths you typed. The file is shared with other people only when you save an export of it and send it yourself.
- Your personal settings (last files and folders, active setup) are stored in %AppData%\LeonS\Outproof. The verification history (add-on) is stored in %AppData%\LeonS\Outproof\history: for each verification the date, the IFC file name, the setup name and version, and counts of elements, differences and findings. It contains no element content.
- IFC files you choose are read on your computer by Outproof's own reader. They are not changed, copied or sent anywhere. When you press Export now, Revit's own IFC exporter writes the file where you choose.
- Reports you save (text, CSV, XLSX) are written only where you choose. They contain element names, categories, ids, GlobalIds and the project name, and you are responsible for who receives them.
- Outproof reads the add-in manifests (.addin files) in the Revit add-in folders to look for duplicate IFC exporter and importer registrations. It reads their names and paths only and does not send them anywhere.
- A small encrypted licence cache and your trial start time are stored on your computer in your Windows user area (%LocalAppData%\LeonS\Licensing and the Windows registry key HKEY_CURRENT_USER\Software\LeonS\outproof). The cache holds only a one-way hash of your Autodesk user id and the dates of the last licence checks.
- Log files, which contain technical messages but never model content, your user id or file names, are stored in %LocalAppData%\LeonS\Outproof\logs and are deleted automatically after 14 days.
We never read these files remotely.

4. Network use
Outproof contacts one service: the Autodesk App Store licence service (apps.autodesk.com), to check whether your signed-in Autodesk account has purchased Outproof or subscribed to its add-on. This request carries your Autodesk user id and the application identifier, as required by Autodesk, and is handled under Autodesk's own privacy statement. We do not receive the result or the request. Outproof makes no other network connections.

5. Sharing and third parties
We do not sell, share or disclose information, because we do not receive any. The only third party involved is Autodesk (licence check, section 4); Autodesk handles that request under its own privacy statement and data protection commitments.

6. Children
Outproof is professional software and is not directed at children.

7. Retention, deletion and consent
- Data inside your model stays until you delete it. Local files stay until you delete them (the list is in section 3). Log files are deleted automatically after 14 days.
- Outproof does not ask for consent to collect personal data because it collects none. If you do not want the licence check to run, sign out of Autodesk in Revit or uninstall Outproof; the 24-hour trial and purchased features then stop working as described in the licence terms, and you can revoke this at any time by signing in again.
- To request deletion of anything we hold about you, write to atulhritik@hotmail.com. We hold no personal data, and will confirm that in writing.

8. Your choices
You can delete the note from a model, and the history and settings from your computer, with the "Remove all Outproof data" button in the ? guide. Your setup library is kept; delete %AppData%\LeonS\Outproof\library.json yourself if you want it gone. Outproof will then treat the computer as new (the 24-hour trial is not restarted for a previously started trial on the same Windows user, and purchases are restored by signing in to Autodesk).

9. Changes
If this policy changes, the new text is published with the next version of Outproof on the Autodesk App Store, with a new effective date.
