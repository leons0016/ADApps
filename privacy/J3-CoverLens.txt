PRIVACY POLICY - CoverLens and CoverLens Plus (JetBrains IDE plugins)

Vendor: LeonS

1. Summary

CoverLens reads coverage reports and source files in your project on your computer. It does not collect or transmit any data. It has
no accounts, no analytics, no advertising, no telemetry and makes no network connection of its own.

2. What the plugins do with your data

- CoverLens reads the coverage report files you load or configure (for example lcov.info, coverage.xml, jacoco.xml, cover.out) and the
  source files of your project that those reports mention. The reports are parsed in memory; the parsed result is kept in memory only
  and is discarded when you close the project or press Clear. Fingerprints (hashes) of source files are kept in memory only, to
  detect that a file changed after a report was written.
- For diff coverage and the commit check, CoverLens runs read-only commands of your own local git executable (rev-parse, symbolic-ref,
  merge-base, diff, ls-files, for-each-ref) and, for the commit check, reads the content of the files in the commit from the IDE.
  Nothing is changed in your repository and the results are used only to draw numbers and markers in the IDE.
- CoverLens never runs your tests, builds or other programs, and never uploads coverage data to any service.
- The plugins contain no analytics library, no crash-reporting service and no "check for updates" call.

3. Data stored on your computer

- Application settings in the IDE configuration folder (file options/coverlens.xml): threshold, display options, size limit.
- Per-project personal settings in the project's .idea/workspace.xml: your own report sources, whether coverage is shown, the chosen
  base branch and, if you use the Plus add-on, a history of up to 30 entries (date, report file name, percentages).
- An optional team file .coverlens.json in your repository, only if you choose "Share with team" or create it yourself.
Uninstalling the plugin does not delete your repositories, reports or .coverlens.json.

4. Licences and purchases

Sales, payments, invoices, taxes and licence keys are handled by JetBrains Marketplace under JetBrains' own terms and privacy
policy. The plugin only reads the signed licence confirmation that the IDE already holds, through the official IDE licensing API,
and checks its signature locally. It does not send licence information anywhere. The vendor receives sales reports from JetBrains
but does not receive your personal data from the plugin.

5. Error reports

If the IDE shows an error from the plugin you may choose "Report by Email". This only opens your own mail client with a draft that
contains the plugin name and version, the stack trace and any text you typed, with operating-system user names removed from paths.
Nothing is sent unless you send the email yourself, and you can edit or delete the draft first.

6. Children

The plugins are developer tools and are not directed at children.

7. Your rights

Because the vendor does not receive personal data from the plugins, there is no personal data to access, correct or delete. If you
sent the vendor an email, you can ask for your email to be deleted by writing to the contact address above.

8. Changes

If this policy changes, the new version will be published at the URL above with a new effective date.
