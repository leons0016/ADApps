Public URL: https://raw.githubusercontent.com/leons0016/ADApps/main/privacy/J4-PlaywrightStudio.txt

1. Summary

Tracelark runs entirely inside your JetBrains IDE and on your own computer. It does not collect, store or transmit
personal data or source code to the vendor or to any third party. It has no accounts, no analytics, no advertising and no telemetry.

2. What the plugins do with your data

- The plugins start the tools that are already installed in your project: Node.js with your @playwright/test, or Python with pytest and
  pytest-playwright. They read the test lists, results, error messages, trace file paths and your test files to show them to you in the
  IDE. This information never leaves your computer through the plugin.
- Listing tests executes your project's Playwright configuration (code). For that reason the plugin lists tests only in projects you have
  marked as trusted in the IDE.
- The plugin itself makes no network connection. It contains no analytics library, no crash-reporting service and no "check for updates"
  call. Network traffic can only come from the tools you run (for example your tests, your dev server, "playwright install", or the
  Playwright Trace Viewer and HTML report, which are started on your computer and serve pages only on localhost).
- The optional dev server keeper starts the command you typed in the settings, exactly as typed, in your project folder.
- The recorder (Plus) starts Playwright's code generator with the address you type; the recorded steps are written to a temporary file
  in the IDE system folder, inserted into your file and the temporary file is deleted.

3. Data stored on your computer

- Project settings: in the project's .idea/workspace.xml.
- Helper files (a Playwright reporter and a pytest plugin, both shipped inside the plugin) in the IDE system folder under "pwstudio".
  They are removed when the plugin is uninstalled.
- A cache of the last test list and the last test results (at most 5,000 entries) in the same folder.
- With the Plus add-on: a flaky test history (the last 20 outcomes of each test, at most 2,000 tests; test names and the letters P, F, K) in the same folder.
- Run configurations of type "Playwright" in the project's run configuration storage.
Nothing is written into your project folders by the plugin except what you ask for (inserted recorded steps, settings file if shared).

4. Licences and purchases

Sales, payments, invoices, taxes and licence keys are handled by JetBrains Marketplace under JetBrains' own terms and privacy policy.
The plugin only reads the signed licence confirmation that the IDE already holds, through the official IDE licensing API, and checks
its signature locally. It does not send licence information anywhere. The vendor receives sales reports from JetBrains but does not
receive your personal data from the plugin.

5. Error reports

If the IDE shows an error from the plugin you may choose "Report by Email". This only opens your own mail client with a draft that
contains the plugin name and version, the stack trace and any text you typed, with operating-system user names removed from paths.
Nothing is sent unless you send the email yourself, and you can edit or delete the draft first.
