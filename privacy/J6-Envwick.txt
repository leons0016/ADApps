PRIVACY POLICY - Envwick and Envwick Plus (JetBrains IDE plugins)

Vendor: LeonS
Contact: atulhritik@hotmail.com
Effective date: 2026-10-30
Public URL: https://raw.githubusercontent.com/leons0016/ADApps/main/privacy/J6-Envwick.txt

1. Summary

Envwick and Envwick Plus work on your computer. They do not collect or transmit any data. They have no accounts, no analytics, no
advertising, no telemetry and make no network connection of their own. The secret values you give Envwick are never sent anywhere
by the plugins.

2. What the plugins do with your data

- Envwick stores the secret values you enter, or import from a .env file, in the secure credential store of your IDE (the "password
  safe"). Depending on your system this is the macOS Keychain, the Windows Credential Manager, libsecret on Linux, or the IDE's own
  encrypted database. The plugin does not write secret values to any file of your project or of the IDE configuration.
- When you run, debug or test a run configuration that you bound to a profile (or a .env file with references), Envwick reads the
  values from the credential store and adds them to the environment of that process. For hiding the values in the console, the values
  that were added are also kept in memory until you close the IDE or use "Forget values held in memory" in the settings.
- The .env importer reads the file you choose and rewrites it in your project; the values go to the credential store.
- The .gitignore check reads the names of files in your project and your .gitignore files. It reads a .env file only to count values and to
  load it for a run configuration you bound to it. It does not run git commands.
- Envwick Plus reads the text of the files in a commit (only the added lines are checked), or of the files in your project when you start
  a scan, and compares them with a bundled rule pack on your computer. Findings are kept in memory and are never written to a file unless
  you export an audit report. An audit report names profiles, key names, run configurations, files and line numbers; it contains no
  secret value. Where it is saved is your choice.
- The plugins contain no analytics library, no crash-reporting service and no "check for updates" call. Rule pack updates arrive with
  new plugin versions, or from a file you load yourself.

3. Data stored on your computer

- Application settings in the IDE configuration folder (options/envwick.xml and options/envwick-plus.xml): masking options, scan options.
- In the project, the file .idea/envwick.xml: the names of your profiles and the names of their variables, and a random project id used to
  keep credential store entries of different projects apart. No values. You may commit this file or add it to .gitignore.
- In your run configurations: the variables ENVWICK_PROFILES and ENVWICK_ENV_FILE, which hold profile names and a file path.
Uninstalling the plugins does not remove entries from your credential store. Delete a profile in Envwick to remove its values first.

4. Licences and purchases

Sales, payments, invoices, taxes and licence keys are handled by JetBrains Marketplace under JetBrains' own terms and privacy policy.
The plugins only read the signed licence confirmation that the IDE already holds, through the official IDE licensing API, and check its
signature locally. They do not send licence information anywhere. The vendor receives sales reports from JetBrains but does not receive
your personal data from the plugins.

5. Error reports

If the IDE shows an error from a plugin you may choose "Report by Email". This only opens your own mail client with a draft that contains
the plugin name and version, the stack trace and any text you typed, with operating-system user names removed from paths. Nothing is
sent unless you send the email yourself, and you can edit or delete the draft first.

6. Children

The plugins are developer tools and are not directed at children.

7. Your rights

Because the vendor does not receive personal data from the plugins, there is no personal data to access, correct or delete. If you sent
the vendor an email, you can ask for your email to be deleted by writing to the contact address above.

8. Changes

If this policy changes, the new version will be published at the URL above with a new effective date.
