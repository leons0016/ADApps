PRIVACY POLICY - FlowPilot and FlowPilot Plus (JetBrains IDE plugins)

Vendor: LeonS
Contact: atulhritik@hotmail.com
Effective date: 2026-10-24
Public URL: https://raw.githubusercontent.com/leons0016/ADApps/main/privacy/J1-FlowPilot.txt

1. Summary

FlowPilot runs entirely inside your JetBrains IDE. It does not collect, store or transmit personal data or source code to the
vendor or to any third party. It has no accounts, no analytics, no advertising and no telemetry.

2. What the plugins do with your data

- FlowPilot reads and changes the Git repositories you have open in your IDE by running your own local git executable
  (for example branch, merge, tag, stash, log and config commands). Branch names, commit metadata and file paths are read only
  to show them to you in the IDE and never leave your computer through the plugin.
- Network access happens only when a workflow step that you start runs "git fetch" or "git push" (or deletes a remote branch)
  against your own remote. These commands are executed by your local git with your existing credentials. FlowPilot never sees,
  stores or transmits your passwords, tokens or keys.
- The plugin itself makes no other network connection. It contains no analytics library, no crash-reporting service and no
  "check for updates" call.

3. Data stored on your computer

- Application settings in the IDE configuration folder (file options/flowpilot.xml).
- The state of a run that is in progress (so it can be resumed), in the project's .idea/workspace.xml.
- Stack information in your repository's .git/config (keys branch.<name>.flowpilot-parent and flowpilot-base) and, if you use
  the Plus add-on, git stashes named "FlowPilot workspace: <branch>".
- Optional team workflow file .flowpilot.yml in your repository, if you create it.
You can remove the stack keys with Settings > Tools > FlowPilot > "Clean up repository metadata". Uninstalling the plugin does not
delete your repositories, stashes or files.

4. Licences and purchases

Sales, payments, invoices, taxes and licence keys are handled by JetBrains Marketplace under JetBrains' own terms and privacy
policy. The plugin only reads the signed licence confirmation that the IDE already holds, through the official IDE licensing API,
and checks its signature locally. It does not send licence information anywhere. The vendor receives sales reports from JetBrains
but does not receive your personal data from the plugin.

5. Error reports

If the IDE shows an error from the plugin you may choose "Report by Email". This only opens your own mail client with a draft that
contains the plugin name and version, the stack trace and any text you typed, with operating-system user names removed from paths.
Nothing is sent unless you send the email yourself, and you can edit or delete the draft first.

6. Children

The plugins are developer tools and are not directed at children.

7. Your rights

Because the vendor does not receive personal data from the plugins, there is no personal data to access, correct or delete. If you
sent the vendor an email, you can ask for your email to be deleted by writing to the contact address above.

8. Changes

If this policy changes, the new version will be published at the URL above with a new effective date.
