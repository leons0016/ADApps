# TableKit help

Real tables in Revit: merged cells, formulas and Excel import, with no Excel needed. Works in Revit 2025, 2026 and 2027.

## Getting started
1. Install TableKit from the Autodesk App Store, start Revit and open a project. A **TableKit** tab appears on the ribbon. It is free for 24 hours from the first start; after that a one-time purchase unlocks it.
2. **New table.** Choose a template (general notes, revision table, door legend, finish schedule, sheet index, or the Indian FAR/FSI area statement) or start blank, and choose where it goes: a new drafting view, a new legend view, or the current view.
3. **Edit like a spreadsheet.** Type or paste data, merge cells, set column widths, row heights, fonts, colours, borders, alignment and number formats (including Indian digit grouping). Formulas such as SUM, AVERAGE, MIN, MAX, COUNT, ROUND, IF, AND, OR and TEXT work, and references follow when you insert or delete rows and columns.
4. **Place.** The table is drawn as ordinary Revit lines, filled regions and text.
5. **Edit again.** Select any part of the table and click **Edit table**, then Apply: it is redrawn in one undo step. Move the top-left text and the whole table follows. A copy in another view is independent.
6. **Import** a CSV or Excel file from New table; Excel does not need to be installed.
7. **Legends.** Put a table in a legend and place that legend on as many sheets as you need.

## Optional add-on (the "Try add on feature" panel)
- **Linked files:** keep a table linked to its Excel or CSV file, see which tables have newer data and refresh them.
- **Export** a table to CSV or XLSX, keeping formulas, merges, widths and formatting.

## The ? button
The **?** button on the Help panel opens the full in-app guide: every feature, each step and where to find it, plus plans, licence, privacy and data topics.

## Removing data
Use **Remove all TableKit data** in the guide. Tables already drawn stay in the model as normal Revit elements.
